# 参赛项目

本仓库用于存放参赛项目的源码、文档与素材。

## 目录结构

```
参赛项目/
├── README.md     项目说明
├── docs/         设计文档、方案说明
├── src/          源代码
└── assets/       图片、演示素材
```

## 快速开始

```bash
git clone https://github.com/jianyilin1024/参赛项目.git
cd 参赛项目
```

## 说明

- 本仓库由 GitHub CLI 创建，默认私有，可在仓库 Settings 中改为公开。
- 提交前请确认 `git config user.name` / `user.email` 与 GitHub 账号一致，否则提交不会计入贡献图。
